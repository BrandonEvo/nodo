================================================================================

  # 0. Clonar repo y copiar .env
  git clone <repo-url> /home/bparedesc1/Docker/nodo
  cd /home/bparedesc1/Docker/nodo
  cp .env.example .env
  # Editar .env con los valores reales (ver sección VARIABLES más abajo)

    -v $(pwd)/frontend:/app \
    -w /app \

  #   - alembic upgrade head  (migraciones)
  #   - python seed.py        (datos maestros)
  #   - uvicorn main:app      (servidor)

  # 3. Verificar que todo está healthy
  docker ps
  curl http://35.208.20.242/health          # debe responder {"status":"ok"}
  curl http://35.208.20.242/                # debe servir index.html de React

FIXES ADICIONALES (2026-05-30) — Login externo + Google OAuth
================================================================================

PROBLEMA 1: API URL hardcodeada en el bundle
  Síntoma: login no responde desde afuera (el browser llamaba a localhost:8000 del cliente).
  Causa:   api.ts usaba `|| 'http://localhost:8000'` como fallback. El build sin
           VITE_API_URL incrustaba esa URL en el JS. El || no distingue '' de undefined.
  Fix:     frontend/src/lib/api.ts
             import.meta.env.VITE_API_URL || 'http://localhost:8000'
             →  import.meta.env.VITE_API_URL ?? ''
           Con baseURL='' axios usa URLs relativas → nginx las proxea a backend. ✓
           En dev, VITE_API_URL=http://localhost:8000/api sigue funcionando. ✓

PROBLEMA 2: Google OAuth redirige a localhost
  Síntoma: al hacer login con Google aparece redirect a localhost:5173/dashboard.
  Causa:   auth_google.py tenía FRONTEND_URL y BACKEND_URL hardcodeados a localhost.
  Fix:     backend/core/config.py — agregar settings:
             BASE_URL: str = "http://localhost:8000"   (default dev)
             FRONTEND_URL: str = "http://localhost:5173" (default dev)
           backend/api/routers/auth_google.py — usar settings:
             FRONTEND_URL = settings.FRONTEND_URL
             BACKEND_URL  = settings.BASE_URL
           .env — agregar para producción:
             BASE_URL=http://35.208.20.242
             FRONTEND_URL=http://35.208.20.242

  ACCION MANUAL REQUERIDA EN GOOGLE CLOUD CONSOLE:
  → APIs & Services → Credentials → tu OAuth 2.0 Client ID
  → Authorized redirect URIs: agregar  http://35.208.20.242/api/auth/google/callback
  → Authorized JavaScript origins: agregar  http://35.208.20.242
  (El redirect_uri actual estaba en localhost:8000, Google lo rechaza en producción)
